Ledger — Personal Budget Tracker

A lightweight, no-signup budget tracker built with Vanilla JavaScript, HTML, and CSS. Log income and expenses, set monthly budgets per category, and see live totals and progress — all persisted locally in the browser.

Features
  Add income/expense transactions (amount, category, description, date)
  View and delete transactions (most recent first)
  Set a monthly budget limit per category, with a progress bar and over-budget warning
  Live running totals for income, expenses, and balance
  Filter transactions by category and sort by date or amount
